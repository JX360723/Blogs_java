## 1. 产品定位与首版范围

**定位**：个人知识博客，记录学习过程、技术实践、生活兴趣与爱好分享。首版优先服务站点所有者本人，访客以阅读浏览为主。

**首版做**：文章（Markdown 写作 + 分类 + 封面 + 置顶 + 搜索）、分类管理、管理员登录、访客端列表 / 详情。

**首版不做**：开放注册、用户投稿、评论、点赞、关注、私信、多用户角色体系、站点设置后台（配置写死前端）。

**已确认决策**：标签纳入 MVP 但排在分类之后（阶段 3）；认证用无状态 JWT，MVP 不强制依赖 Redis；前端技术栈锁定 Vue3 + 纯 JavaScript。
